# EMBTA Website

Demo website for **Eastern Maring Business & Traders Association (EMBTA)**.

## Features
- Responsive single-page design
- About EMBTA
- Services
- Vehicle registration categories
- Notices and updates
- Contact desk
- GitHub Pages deployment workflow

## Local preview
Open `index.html` directly in a browser, or run:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
The repository includes a GitHub Actions workflow for deploying the static website to GitHub Pages.

Deployment trigger refreshed on 20 September 2026.
